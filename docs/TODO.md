### Інструкція: підключення Cloudflare Pages (~15 хв, разом)
1. Зареєструйтесь на https://dash.cloudflare.com (безкоштовний план).
2. Workers & Pages → Create → Pages → Connect to Git → авторизуйте GitHub → оберіть репозиторій `SpaceNamee/KarpatskaSadyba`.
3. Build settings: Framework preset = **Astro**, build command `npm run build`, output `dist` (підставиться автоматично).
4. Deploy → отримаєте тимчасовий URL виду `*.pages.dev` — надішліть мені, перевірю.
5. Custom domains → Add → `karpatska-sadyba.com.ua` → Cloudflare покаже NS/CNAME-записи → у панелі hostiq.ua змініть NS-сервери домену на вказані Cloudflare (найпростіший шлях; SSL підніметься автоматично, зміна NS діє до 24 год).
