## 1. Бізнес-контекст

**Що:** «Карпатська садиба» — 3 окремі дерев'яні котеджі (вілли) у с. Плав'я, ~5 км від ГК «Плай», Сколівські Бескиди. ≈38 базових спальних місць, до 49 з додатковими. Рейтинг Booking.com **9.2**.

**Головна ціль сайту: прямі бронювання.** Сайт має переконати гостя залишити заявку напряму (телефон / форма), замість бронювання через Booking.com (комісія ~15%). Кожне переведене бронювання = ~1 400–2 400 грн збереженої комісії за добу.

**Другорядні цілі:**
- База для просування: Google-пошук (SEO) + Google/Instagram реклама (лендинг, на який не соромно вести трафік).
- Збір статистики: звідки приходять гості, що дивляться, де губляться.
- Довіра: справжній сайт з доменом = легітимний бізнес, а не «оголошення».

**Метрики успіху (перший рік):**
- Заявки з сайту: ≥ 5/міс у сезон (форма + кліки на телефон, відстежуємо в GA4).
- Позиції Google: топ-10 за запитами виду «котедж Плав'я», «котедж біля Плай», «садиба Карпати для великої компанії».
- Lighthouse: Performance/SEO/Accessibility ≥ 90 (мобільний).

## 3. Конкуренти

> Повний аналіз: `docs/COMPETITORS.md` (5 сайтів + сусіди без сайтів + аналіз видачі Google).

**Головні висновки:**
- **Вільна позиція: «великий котедж на 10–18 осіб біля Плаю».** Локальні конкуренти з сайтами закривають максимум 8–10 осіб на об'єкт: «Біля Плаю» (Плав'я, та сама вулиця!) — 8, Villa Alpiyka — 10, «Аляска» — по 4. Це — головний месидж hero і title головної.
- **Календаря зайнятості немає ні в кого** в регіоні (навіть у еталонного TAOR) — наш календар з Booking iCal буде унікальною перевагою.
- **Ціни показуємо прямо на сайті** (наші 9 500–12 000 грн за 10–14 осіб конкурентні проти 8 000 грн/8 осіб у сусідів). Ховати прайс (як Альпійка в Google Drive) — антипатерн.
- **SEO-ніша відкрита:** за «котедж біля Плай» серед власних сайтів ранжується лише bilya-plaiu.com.ua; за «котедж для великої компанії + Львівські Карпати» не бореться ніхто локальний.
- Порівняння з Booking на сайті **не робимо** (рішення власниці): прямі бронювання стимулюємо м'яко — зручною заявкою, календарем і телефоном в один клік, без гасел типу «напряму дешевше».
- **⚠️ Конфлікт імені:** у Волосянці існує інша «Карпатська садиба» (до 10 осіб, біля «Захар Беркут»). У title і Google Business Profile завжди уточнюємо «Плав'я / біля Плаю».
- З COMPETITORS.md у беклог: ідея знижки за раннє/повторне бронювання (відв'язування від Booking); сторінка «Корпоративи» підтверджена як сильна SEO-посадкова (фаза 4).

## 6. Функціонал

### 6.1 Календар зайнятості (v1)
- Джерело: **iCal-експорт Booking.com** для кожного з 3 котеджів (стандартна функція екстранету).
- Serverless-функція `GET /api/availability?cottage=1..3` тягне iCal, кешує ~1 год, віддає зайняті інтервали.
- На сторінці котеджу — календар на 2–3 місяці: зайняті дати сірі. Підпис: «Календар орієнтовний — підтвердження по телефону».
- Прямі (телефонні) броні власниця, як і зараз, вносить у календар Booking — сайт підхопить автоматично. Окремої адмінки не потрібно.

### 6.2 Форма заявки
- Поля: котедж (передвибраний), дата заїзду/виїзду, к-сть гостей, ім'я, телефон (обов'язкові), коментар.
- `POST /api/booking-request` → валідація + анти-спам (honeypot + rate limit) → повідомлення у **Telegram** власниці (Bot API, безкоштовно).
- Відповідь гостю на сторінці: «Дякуємо! Передзвонимо протягом кількох годин» + телефони для швидкого зв'язку.
- Без бази даних у v1: Telegram-чат і є журналом заявок.

### 6.3 ШІ-помічник (фаза 3)
- Чат-віджет (кнопка внизу праворуч): відповідає на питання про ціни, місткість, послуги, як доїхати; рекомендує котедж під розмір компанії; підводить до заявки.
- `POST /api/chat` → Claude API (Haiku — найдешевша модель), системний промпт = база знань, згенерована з `about.md`.
- Обмеження витрат: ліміт повідомлень на сесію/IP, денний ліміт бюджету, фолбек «зателефонуйте нам». Очікувана вартість ~$3–10/міс.
- Не видає цін/умов, яких немає в базі знань; на невідоме — чесно каже «уточніть за телефоном».

### 6.4 Instagram-стрічка
- v1: курований блок 6–8 фото з підписом «@karpatska_sadyba_plavie» і посиланням на профіль (без API — надійно і швидко).
- Пізніше можливий автоматичний віджет (Instagram Basic Display API вимагає токенів і періодичного поновлення — свідомо відкладено).

### 6.5 Аналітика
- **GA4**: перегляди, джерела, події конверсії — `booking_request_submitted`, `phone_click`, `chat_opened`.
- **Google Search Console**: індексація, пошукові запити.
- Cookie-банер не потрібен, якщо GA4 у режимі без реклами; переглянемо при запуску реклами.

## 7. SEO

Поточний сайт **заблокований для Google** (`noindex, nofollow`) — новий сайт це виправляє в корені.

- Власний домен (пропозиція: `karpatska-sadyba.com.ua`), 301-редіректи зі старого github.io.
- Кожна сторінка: унікальні `title`/`meta description` укр+англ, `hreflang` для UA/EN пар.
- Структуровані дані schema.org: `VacationRental`/`LodgingBusiness` (адреса, рейтинг, зручності), `FAQPage` на цінах.
- Семантичний HTML, один `h1` на сторінку, alt-тексти всіх фото (укр/англ).
- `sitemap.xml` + `robots.txt` (генерує Astro), реєстрація в Search Console.
- Google Business Profile (картка в Google Maps) — задача власниці, найсильніший локальний сигнал.
- Цільові запити: «котедж Плав'я», «котедж біля Плай», «садиба Сколівські Бескиди», «котедж в Карпатах для великої компанії», «оренда котеджу Славське район».

## 8. Дизайн і бренд

- **Назва:** «Карпатська садиба» — без змін. Англійською: **“Karpatska Sadyba — Carpathian Estate”** (виправляємо помилку «Carpation» у поточному лого).
- **Логотип:** оновлений, простий (шрифтовий знак + гірський/дерев'яний мотив), SVG.
- **Палітра:** відштовхуємось від поточної зеленої гами сайту, але приглушуємо: глибокий лісовий зелений (основний), теплий дерев'яний/бежевий (фони), темно-сірий текст, один яскравий акцент для CTA. Точні токени — на етапі дизайну (фаза 1), затверджує власниця по прототипу головної.
- **Типографіка:** Philosopher (заголовки — зберігає впізнаваність, підтримує кирилицю) + сучасний гротеск для тексту (наприклад, Inter/Manrope), self-hosted.
- **Стиль:** великі фото, багато повітря, теплий тон. «Затишок і запах дерева», не рустик-кітч.
- **Анімації:** стримані — плавна поява блоків при скролі, м'які hover, лайтбокс-галерея. Поважаємо `prefers-reduced-motion`.

## 10. Якість: адаптивність, доступність, швидкість

- **Mobile-first**: більшість трафіку з Instagram/реклами — телефони. Брейкпоінти ~360 / 768 / 1024 / 1440.
- **Доступність (WCAG 2.1 AA):** контраст ≥ 4.5:1, фокус-стани, навігація з клавіатури, alt-тексти, aria-підписи форм і календаря, `prefers-reduced-motion`.
- **Швидкість:** LCP < 2.5 c на мобільному 4G, CLS < 0.1; бюджет сторінки ≤ ~300 КБ без фото; шрифти self-hosted із `font-display: swap`.
